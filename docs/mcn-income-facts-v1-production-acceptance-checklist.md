# MCN 收入事实 V1 生产验收记录清单

> 用于完成 Timo 与 Linky 的“数据获取准确”验收。它不是奖励、分账或资金动作的放行单；所有相关开关必须持续关闭。

## 0. 验收前置条件

- 当前部署版本已包含：持续同步恢复、跨日最新修订保护、撤销原流水阻断。
- `MCN_INCOME_FACTS_ENABLED=false`、`MCN_INCOME_FACTS_CONTROLLED_READ_ONLY_ENABLED=false`、`REWARD_ENGINE_ENABLED=false`、`LIFECYCLE_SHADOW_ONLY=true` 已由容器环境复核；不得记录或展示 Secret。
- 双方已确认平台、业务日、窗口和 MCN 协查联系人；协查使用时间、`X-Request-Id`、HTTP 状态与脱敏计数。

## 2. 受控异常与恢复证据

每项写明：可用样本平台和业务日、MCN 预期、BANDEIRA 实测、请求关联号、结论；没有安全样本时标记“无安全样本”，并保留 MCN 的书面说明。

| 场景 | BANDEIRA 必须证明的结果 | 证据 / 结论 |
|---|---|---|
| 同日历史修订 | 原始账本同时保留版本；影子账本仅采用最新版本；对账匹配 |  |
| 跨日更正 | 旧业务日不再投影，新业务日仅保留最新事实；两日不双计 |  |
| `REVERSAL` / `REVERSED` / `CANCELLED` | 原流水与撤销事实均保留；原流水不再进入候选，状态为作废 |  |
| `ADJUSTMENT` | 按 MCN 已书面确认的经济语义投影；语义不清时不得进入候选 |  |
| `STALE` | 维持待重试/待确认；绝不解释为零收入或已完成 |  |
| HTTP 429 / 503 | 不前移游标；记录可重试状态；从原游标安全恢复 |  |
| 签名失败 | 拒绝响应、记录脱敏错误；不写入收入事实、不前移游标 |  |
| 中断后续传 | 已接受页面仅产生重复计数；最终读到末页并可对账 |  |

## 3. 关闭受控窗口后的复核

- [ ] 受控只读入口已关闭，持续消费者仍关闭。
- [ ] 奖励、分账、钱包、提现、付款开关均保持关闭。
- [ ] 未归属、冲突、等待定稿事实的处理结论可在运营端追溯。
- [ ] 每项场景的证据已写入发布/联调记录；不包含账号、事实明细、游标、签名或 Secret。
- [ ] 数据负责人和业务负责人共同确认：只读收入事实链路准确；**该确认不等于批准发奖**。

## 4. 进入奖励门禁前仍需单独完成

即使本清单全部通过，也只能证明收入事实的获取、留存和影子投影正确。开启奖励前还必须完成规则版本、邀请关系和公会归属快照、逐笔人工核对、财务签字、回滚预案，以及单独的奖励开关审批。
