# 参考货币展示与人工积分调整

## 口径

C 端根据用户当前归属国家及当前生效的后台积分汇率展示对应货币参考金额；未配置、停用或读取失败时显示积分。各工作区只展示对应应用；手动调整以积分为单位且必须指定 Timo 或 Linky。人工增加即时计入可用积分，扣减允许可用积分为负，冻结批次不受影响。各应用余额可以有正负数，用户总账为所有应用的合计。

## 账务

人工调整通过财务权限及应用、国家范围校验，独立记录用户、应用、积分变动、原因、操作人、变更前后应用可用余额、时间与请求编号。同一请求编号可安全重试，不重复记账。记录与用户总账户在同一事务中更新；用户账户流水按用户、应用合并读取，人工调整不进入下级分佣报表。原下级收入冲正允许可用积分负数，不改其他冻结批次。提现与现金支付不在本次范围。

## 汇率与迁移

V84 增加人工调整表、增加 CO/COP、CL/CLP、VE/VES、PE/PEN 的国家映射；不创建任何汇率、不改历史账户。管理员需自行为国家配置有效参考汇率。原五个国家维持既有数据和版本。

C 端余额参考金额通过身份认证、工作区权限校验从服务端获取；流水和分佣明细的参考金额按批由服务端十进制计算。为避免浏览器数字精度不足导致错误换算，单笔积分数超出浏览器六位小数安全表示范围时保留积分显示；计算请求失败时同样回退积分。汇率是参考价格，不表示真实现金或可提现金额。

## 核验与未完成

本地隔离 H2 已验证：Timo 人工扣减可为负、请求重试不重复记账、Linky 不受影响、注册国家的未配置汇率回退积分、配置测试汇率后负值可正确换算。后台与 C 端页面使用独立测试账号核验；前端、后端测试结果以 PR 描述为准。测试汇率及测试用户只存在本地，不得导入生产。生产 V84、权限和各国家汇率需在受控发布时核验；本次不自动发放邀请核验活动奖励。

## 账目维护入口

旧版后台财务管理下提供独立“账目维护”页面，列表显示人工维护记录；点击“调账”后，通过用户 ID 异步读取用户信息，再选择应用、增加或减少、积分数量并填写原因。原“用户账户”页面保留账户查询，不提供调账表单。记录列表受财务权限以及平台和国家范围约束。
