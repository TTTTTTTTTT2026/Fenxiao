# 导师分成影子账本 V1

## 业务边界

导师分成与邀请裂变分成、运营分红是三条独立的业务链路：

- **邀请裂变分成**：按收入事实、邀请关系和比例策略演算；
- **导师分成**：导师与学员关系生效后，学员达成生命周期里程碑时，向导师写入固定额度的影子记录；
- **运营分红**：基于独立的团队经营利润事实，不在本模块处理。

本模块只写 `incentive_shadow_ledger`。它不会创建奖励记录、钱包余额、提现申请或付款指令。

## 规则口径

每条导师规则只对应一个里程碑和一个适用范围：平台、国家、可选公会、固定额度、单位、冻结天数及生效区间。

支持的里程碑为：

1. `VALID_72H_START`：学员在注册后 72 小时内完成有效平台启动；
2. `FIRST_INCOME`：学员首次收入；
3. `FIRST_WITHDRAW_ELIGIBLE`：学员首次达到平台可提现门槛；
4. `ACTIVE_7D`：学员连续活跃 7 天；
5. `ACTIVE_30D`：学员连续活跃 30 天。

规则以“草稿 → 审批启用 → 停止使用”管理。同一里程碑、平台、国家、公会范围的两个启用规则不得在生效期重叠。

## 关系与时间口径

- 导师资格由运营设置国家、语言和最大带教人数；
- 学员归属使用独立的 `mentor_assignment_version` 关系版本，不读取邀请关系；
- 学员达成里程碑时，只读取当时仍有效的导师归属和规则；
- 同一导师、学员、平台、里程碑、规则组合由幂等键保证最多生成一条影子记录；
- 后续变更导师、规则或停止规则不会改写已有影子记录。

## 上线门禁

导师模块完成影子核验不代表可以发奖。真实奖励放行前仍需要单独确认：预算、会计科目、冻结到期处理、撤销/冲正、财务审批和从影子账本到奖励账本的受控流程。
