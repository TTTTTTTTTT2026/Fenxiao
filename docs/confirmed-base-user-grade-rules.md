# 生产用户等级基础规则（V1）

普通成员是注册后的默认等级。新星、银牌、金牌分别要求累计直接邀请的有效用户达到 3、10、30 人；同一个有效直邀累计计入后续等级，不因正常停止营业自动降级。有效用户需有本人真实、可结算的聊天收入，并在一个 7 个完整自然日的观察窗内至少有 3 个不同收入日期。当前活跃有效人数与累计达标人数分开显示，不作为自动降级条件。没有额外的个人收入、付费课程或下级总收入门槛。

规则适用于 Timo、Linky 各自的 BR、ID、MX 用户与其已核验公会绑定，不按公会单独开关。首次以 `V64` 数据迁移建立 18 条已启用规则，每条都有规则编号、版本、启用时间和研发发布说明；迁移对同范围现行已启用的全公会规则不覆盖、不重复创建。以后业务调整须新增版本化迁移，不改写已执行版本，也不在运营后台新增或编辑。

本地 MCN 定稿收入进入系统后，会更新有效用户事实；等级每小时第 25 分钟复核已核验且有直邀关系的用户。达到金牌时系统可建立团队，但团队经营分成另受独立许可控制，当前保持关闭。铂金仅接受人工建立 30 天观察记录、系统计算至少 2 名银牌成员各自通过验收、运营最终确认升级。钻石与黑金仍为展示预留，不自动评估或升级。

`REWARD_ENGINE_ENABLED` 与 `REAL_FINANCE_ENABLED` 仍为 `false`。等级资格评估不创建实际奖励、钱包余额、提现或付款。
