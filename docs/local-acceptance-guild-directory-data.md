# 本地验收：公会目录数据集

## 用途

本地运营后台验收时，`平台公会目录`、导师资格、导师分成历史、邀请规则范围及团队相关页面需要可选的权威公会目录。本数据集仅解决该类目录依赖，不用于收入、用户或财务验收。

## 当前数据快照

- 导入日期：2026-09-20
- 来源：生产环境的 `platform_guild_directory` 权威目录副本
- Linky：8 条
- Timo：3 条
- 字段范围：平台、公会 ID、公会名称、国家、公会状态、目录状态及本地导入标记。

## 明确不导入的内容

- MCN 原始收入、影子账本、奖励候选或任何金额；
- 平台账号、手机号、邀请关系、用户资料；
- 管理员会话、密码、接口凭据、签名密钥；
- 钱包、提现、付款或真实奖励数据。

## 本地运行与验收

1. 启动本地后端（`local` profile）和前端开发服务。
2. 在本地后台首次登录后按页面要求修改本地管理员密码。
3. 打开“平台公会目录”，分别选择 Timo 和 Linky，确认可读取 3 条与 8 条目录记录。
4. 在依赖公会选择的页面切换平台、国家，确认只出现该范围内状态可用的公会。`DISABLED` 公会应保留在目录中供查询，但不应成为规则可选项。

## 更新原则

需要更新本地目录时，只能由具有生产环境授权的运维人员执行一次性、字段白名单式导出。不得复制整个生产数据库，也不得为了本地验收开启 MCN 持续同步、真实奖励、钱包、提现或付款能力。
