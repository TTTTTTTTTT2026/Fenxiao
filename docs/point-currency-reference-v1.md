# 积分兑归属国家货币参考汇率 V1

## 已确认业务边界（2026-10-14）

- 第一期金额仅供参考，不是现金、可提现余额、支付承诺或锁定的实际结算价格；不接入旧提现/付款，不修改任何积分账本。
- 以系统保存的用户**当前归属国家**选货币。后台更正归属后，新一次用户试算使用新国家；不固定首次注册国家，也不从IP、语言、登录区号或Timo/Linky工作区推断。
- 当前登录国家对应CN/CNY、ID/IDR、MX/MXN、BR/BRL、HK/HKD。货币由后端固定映射，不接受操作人把印尼改成USD。缺归属、暂不支持的国家、未配置或停用均明确无法计算；不回退美元、不填假0或1比1。
- 积分到货币是独立转换层，不重复配置应用钻石的价值，也不改变钻石兑积分或10%/3%分佣。参考金额为输入积分乘国家有效汇率，只在最后按当前五种货币的两位小数HALF_UP处理。

## 本期能力与页面

- 旧管理后台 `/admin#admin-point-currency-rates`，财务管理 → 积分货币汇率。独立前端模块，仅对原入口做菜单、路由和组件挂载的少量修改；不迁移或扩展未完工新版后台。
- 最高管理员和财务会话可以访问。普通admin、operations及其他角色不能通过本入口或直接调用接口访问；保存与按用户试算另受归属地区scope限制。
- 国家配置表显示固定货币、当前每1积分参考金额、状态/版本/UTC生效时间、未来预约。支持立即启用/停用、未来生效、版本历史分页与财务操作审计。
- 每国家最多一个未生效预约：新保存取消旧预约但保留原内容及取消元数据。立即停用同时取消旧预约，避免未来无意恢复；保存前明示该行为。已生效历史汇率不覆盖，只追加版本。
- 保存时锁定固定国家行，并校验expectedVersion；并发/过期编辑返回409，不能静默覆盖。禁止倒填生效时间，立即生效传null；输入的本机时间明确转为UTC传给后端。
- 预览可按国家或用户ID，两者互斥。按用户只输入ID和积分，由后端读取当前归属；这是手工积分试算，**不是读取该用户真实账户余额**。前端不自行计算金额，输出十进制金额/汇率均用字符串，避免浮点失真。
- 管理页面与服务为真实开发成果。当前C端收益页面仍显示原积分，不新增货币展示入口或用户端公开API；未来展示与鉴权另行接入同一计算逻辑。

## 接口

全部接口需有效 `X-Admin-Session` 及现行FINANCE权限；旧X-Admin-Token不替代财务会话。

| 方法 | 路径 | 内容 |
|---|---|---|
| GET | /admin/finance/point-currency-rates | 五国家当前/预约配置及生成时间 |
| PUT | /admin/finance/point-currency-rates/{country} | enabled、currencyPerPoint、effectiveAt、expectedVersion |
| GET | /admin/finance/point-currency-rates/{country}/history | 50版本/页，beforeVersion向前分页 |
| POST | /admin/finance/point-currency-rates/preview | points及countryCode或userId（互斥） |

汇率必须为正数，最多12位整数/8位小数；停用可不填比例。试算积分为非负数，最多12位整数/6位小数。返回referenceOnly=true、币种、金额、所用汇率版本/生效/计算时刻；不可计算时amount=null并返回明确状态。0积分在有有效率时是真实0.00，不能与未配置混淆。

## 数据库及发布

- V79新增两张小表：五个固定国家/货币映射、独立版本历史。**只种国家，不种任何真实或演示汇率**；不回填积分或历史现金估值、不增加任务/自动同步/外部汇率服务。
- 按国家/生效时间索引查询，预览不扫描收入原表或积分流水。汇率修改及取消预约元数据与审计同事务提交。
- 本期开发不授权生产部署或配置。发布需用户另行授权、备份验证及Flyway V79；上线后仍需业务确认实际汇率，再由有权限人员配置。
- 应用回滚时保留V79表/历史，不删除已执行迁移；本功能从不记账或支付，汇率历史不能当实际结算凭证。

## 自动与本地验收

- 后端覆盖五币种/无默认值、金额精度/舍入、真实0与缺配置、用户改国家/无美元兜底、启停/历史、预约边界/取消、过期版本、地区权限、输入校验、历史分页与积分不变。MockMvc覆盖实际财务会话、无会话/普通角色/旧token拒绝、配置审计与409响应。
- 前端覆盖菜单权限、页面状态、精确金额字符串、无默认美元、未配置与0、日期转换及实际原生日期表单取值。浏览器核验发现原生日期输入可见值未随React状态及时同步；改为以提交表单FormData取值，补回归后实测预约不提前生效。
- 独立本地H2和测试账号/价格，仅在项目根outputs验收启动程序种入。生产代码/迁移无虚拟价格，验收文件不提交Git。本地原后台页面使用真实本地API，不是静态DEMO。
- 本轮不连接生产、MCN或短信；实际现金金额、提现时点/结算汇率锁定、C端展示、生产MySQL迁移验收和生产汇率配置均未完成，不自动补做。
